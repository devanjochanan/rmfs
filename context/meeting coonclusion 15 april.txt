Order batching from previous thesis:
1. Emily
No order batching is used because order batching requires waiting for a certain amount of time or a specific number of orders, which can result in idle picking stations. Therefore, this study adopts the FCFS assignment rule to avoid these issues.

2. Aisyahna
orders are grouped based on SKU similarity using jaccard index. each group becomes 1 batch and assigned to a station. max batches = number of picking station
Flow:
every 5 ticks:
check available bins
calculate pairwise jaccard similarity for each 2 orders
batch orders in to (n available stations) batches based on similarity

calculate sku similarity between current SKU demand for each station
assign each batch to a station
